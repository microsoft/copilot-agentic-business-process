The reference contributes four workflows, two standalone agents (plus an extraction agent node), five agent skills, two review widgets, two roles and a mailbox environment variable. A new process follows this approach; it is not a one-click conversion of any process. Claims, loans and onboarding are possibilities and need their own domain controls and evaluation.
