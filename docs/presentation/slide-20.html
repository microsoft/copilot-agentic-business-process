Presenter notes & sources

The skills install or verify tooling and perform readiness checks before making changes. Core requires Dataverse administrator access and Entra app-registration rights; provisioning an environment adds Power Platform administrator access. Order Processing adds user/license and Exchange administration requirements, a dedicated automation user and a shared mailbox with delegated access. The manual guides are available for the same operations. Developer-side GitHub Copilot access is distinct from runtime Copilot Studio licensing.
