02 / Order Processing

From incoming order to SAP-ready payload

Four workflows. Two explicit human gates. One traceable process instance.

  1. WORKFLOW 1

    Receive

    Email arrives in the shared mailbox.

    Document stored
  2. WORKFLOW 2

    Extract

    Agent reads the document into a fixed JSON contract.

    Structured order
  3. HUMAN GATE 1

    Review

    Verify and correct the extracted order.

    Reviewer decision
  4. WORKFLOW 3

    Validate

    Check products, inventory and promotions.

    Explained findings
  5. HUMAN GATE 2

    Approve

    Accept or reject the agent's evaluation.

    Approver decision
  6. WORKFLOW 4

    Finalize

    Generate and store a schema-bound SAP payload.

    Downloadable JSON
Agent / workflow executionHuman controlRejection at either gate stops that order.
The sample generates the SAP payload. It does not post an order to SAP.

Presenter notes & sources

Walk through the approval path from left to right. Extraction review precedes business validation; evaluation approval precedes SAP payload generation. Both rejection paths close the process. Each stage persists state in Dataverse. The final artifact is a JSON file; ERP posting and its operational safeguards are additional integration work.
